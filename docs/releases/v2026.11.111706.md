## ⚡ 启动与账号页提速

- Windows 进程检测改为系统原生接口，不再逐个起 tasklist / PowerShell 子进程，状态刷新与切换客户端的等待明显变短。
- WorkBuddy 首开「当前登录」从约 5 秒降到约 3 秒（Windows 实测）；Trae 账号页补齐从约 1.8 秒降到约 1.5 秒。
- Qoder 账号页分层显示：本机程序位 / 当前登录不再被上游积分、签到拖住，谁先回来谁先落地。
- Qoder 多账号签到状态查询改为有界并发，「一键刷新」更快；签到领取仍逐个进行，不受影响。
- 窗口来回切换（alt-tab）不再每次都触发整轮状态探测；未安装的区域不再每分钟重复扫描安装位置。
- 运行期间新装到默认目录的客户端仍会被及时认出；装在自定义目录的客户端最多 5 分钟后自动发现。

## ⚠️ 升级说明

- 本版为性能整改，无破坏性变更；数据目录仍为 `~/.buddy-switch`，账号库、网关 Key、签到与用量记录沿用，无需迁移。
- 应用装在非默认目录（便携副本）时，卡片「已安装 / 启动」以缓存路径为准；切换账号不受影响，认证文件始终写到真实账号库。
- 已安装用户可在应用内直接检查并更新。
