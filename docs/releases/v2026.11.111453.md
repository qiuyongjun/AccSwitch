## 🚀 Qoder 逐资源包到期

- 账号卡新增「资源包」浮层：逐个显示资源包的剩余 / 总量、到期日与临期状态，不再只看到一个聚合到期时间。
- 详情抽屉的积分页改为显示真实逐包明细；拿不到时回落聚合额度，并给出「登录网页端 / 读取逐包明细」入口。
- 网页端登录一次即可：会话仅存本机、绑定当前账号、7 天过期；抽屉里可随时「退出网页登录」清除。
- 国际版逐包支持按区域配置出站代理（设置 → 网络）；登录窗仍走系统代理，不受该配置影响。

## 🧾 运行日志

- 设置 → 日志 新增本工具自身的运行日志，网关启动、账号切换、后台任务与崩溃都能在这里看到。
- 日志按日分片、保留 7 天；写盘前会脱敏 token / 密码 / JWT，适合直接复制反馈。
- 支持级别 / 日期 / 关键字筛选、自动刷新、复制、打开日志目录与二次确认清空。

## 🐛 问题修复

- 未登录网页端时，详情抽屉不再误显示「已登录，读取逐包明细」，改为按原因给出「登录网页端」或「读取逐包明细」。
- 修复详情抽屉在没有逐包明细时丢失聚合额度到期信息的问题。
- 切换 Qoder 国内版 / 国际版时清空逐包缓存，避免旧区域的资源包串到当前账号。
- 设置新增「网络」分区时，WorkBuddy / Trae 设置页不再出现空分区。
- 逐包浮层补上限高与滚动，资源包较多时不会被窗口裁掉。

## ⚠️ 升级说明

- 本版无破坏性变更，已安装的旧版可在应用内直接检查并更新。
- 数据目录仍为 `~/.buddy-switch`，账号库、网关 Key、签到与用量记录沿用，无需迁移。
- Qoder 逐包需要桌面版并在网页端登录一次；服务端 / CLI 形态仍显示聚合额度。
