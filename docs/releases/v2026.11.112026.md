## 🚀 Qoder 资源包

- 资源包列表只显示**还能用**的包：用完的、已过期（即使仍有剩余）的一律不显示。
- 仍可用的包按**最近到期**排在最前；长期有效（无到期时间）的排在最后。
- 资源包数量、「共剩」与读取成功提示都按可见包统计；全部不可用时显示「无可用资源包」，不再摆空列表。
- 卡片「资源包」浮层与详情抽屉共用同一套过滤 / 排序，两处不会再给出不同顺序。

## 🐛 问题修复

- 资源包浮层只保留列表一条滚动条（表头固定）；此前外层与列表各有一条，外侧滚动条没有意义。
- 详情抽屉的网页会话说明与「退出网页登录」移到资源包列表上方，包多时不必滚到底才能看到。
- 在卡片「资源包」里读过逐包后，进入详情抽屉不再显示「积分 —」或要求再刷新一次。
- 逐包读取成功后会按需自动补取该账号的聚合额度；聚合暂时读不到时，用逐包合计兜底展示。
- 展示兜底只影响卡片 / 表格 / 抽屉的读数，「优先」排序仍按实时聚合额度计算。

## ⚡ 启动与账号页

- WorkBuddy 账号页的编辑器 / 插件状态探测延后到首屏之后，不再与账号列表、积分和运行状态抢资源。

## ⚠️ 升级说明

- 本版无破坏性变更，已安装的旧版可在应用内直接检查并更新。
- 数据目录仍为 `~/.buddy-switch`，账号库、网关 Key、签到与用量记录沿用，无需迁移。
- Qoder 逐资源包需要桌面版并在网页端登录一次；服务端 / CLI 形态仍显示聚合额度。
