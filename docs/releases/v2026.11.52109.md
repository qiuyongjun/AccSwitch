## 🎉 首个正式发布

- 本仓库首个可用版本：Windows（NSIS）、macOS（DMG，Apple Silicon / Intel）、Linux（deb / AppImage）四类桌面安装包。
- 数据目录仍是 `~/.buddy-switch`，已有的账号库、网关 Key、签到与用量记录可直接沿用，无需迁移。

## 🐛 问题修复

- 修正更新签名公钥配置（此前多编码一层导致桌面打包在生成更新包时失败），本版起安装包可正常产出并支持应用内自动更新。
- 更正 README 与 LICENSE 中的上游仓库地址为 `NextAgentX/qoder-trae-workbuddy-switch`。

## ⚠️ 升级前必读：旧版需手动替换

- 本仓更换了 updater 签名密钥与应用 identifier，上游旧版无法通过应用内自动更新升级到本版，请先退出旧版并手动安装新包。
- 建议先卸载旧版再安装，避免两份应用同时运行并写入同一个 `~/.buddy-switch` 数据目录。
- 安装本版后，后续版本可在应用内直接检查并升级。

## 🖥 发布范围

- 本版只发布桌面安装包；Docker 预构建镜像与在线演示暂未启用，webui 可从源码构建或下载 Release 里的 CLI 裸二进制。
- npm 通道继续关闭，`@nextagentx/*` 包不会随本版发布。
- 许可仍为 PolyForm Noncommercial 1.0.0，原始版权与 Required Notice 保留在 LICENSE。
